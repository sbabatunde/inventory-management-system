## 1. Purchase-to-Store Flow

### Process Steps:
Create Purchase Requisition
↓

Approve Requisition
↓

Create Purchase Order
↓

Send to Supplier
↓

Receive Goods
↓

Stock Updated Automatically

text

### Detailed Workflow:
| Step | Actor | Action | System Response |
|------|-------|--------|-----------------|
| 1 | Storekeeper | Create PR | PR number generated |
| 2 | Manager | Approve PR | Status → Approved |
| 3 | Procurement | Create PO | PO number generated |
| 4 | Procurement | Send PO | Status → Sent |
| 5 | Storekeeper | Receive Goods | Stock increased |
| 6 | System | Update Balance | GR created |

## 2. Installation Release Flow

### Process Steps:
Create Release Form (Installation)
↓

Enter Job Order Number
↓

Fetch from CRM
↓

Auto-fill Destination & Equipment
↓

Add Signatories
↓

Submit for Approval
↓

Approve
↓

Dispatch (Stock Deducted)
↓

Complete
↓

CRM Updated

text

### Detailed Workflow:
| Step | Actor | Action | System Response |
|------|-------|--------|-----------------|
| 1 | Engineer | Create form | Form created as Draft |
| 2 | Engineer | Enter JO number | - |
| 3 | System | Fetch from CRM | Auto-fill data |
| 4 | Engineer | Review & add items | - |
| 5 | Engineer | Add signatories | Signatories added |
| 6 | Engineer | Submit | Status → Pending Approval |
| 7 | Manager | Approve | Status → Approved |
| 8 | Storekeeper | Dispatch | Stock deducted |
| 9 | Engineer | Complete | Status → Completed |
| 10 | System | Notify CRM | CRM updated |

↓ Dispatch
Dispatched
↓ Complete
Completed

text

### Cancellation Points:
- Draft → Cancelled

- Approved → Cancelled

Manual Upload → Pending Reconciliation → Pending Approval → ... → Completed
