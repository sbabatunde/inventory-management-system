## 1. Getting Started

### 1.1 Logging In
1. Open the application URL
2. Enter your email and password
3. Click "Sign In"
4. You'll be redirected to the dashboard

### 1.2 User Roles
| Role | Description | Permissions |
|------|-------------|-------------|
| Super Admin | Full system access | Everything |
| Admin | System administration | Most features |
| Manager | Department management | Module-specific |
| Staff | Regular operations | Basic features |
| User | View only | Read access |

### 1.3 Navigation
- **Sidebar**: Navigate between modules
- **Top Navbar**: Notifications, profile, logout
- **Breadcrumbs**: Current location
- **Search**: Find items quickly

## 3. Inventory Management

### 3.1 Stores
**Creating a Store:**
1. Navigate to Inventory → Stores
2. Click "Add Store"
3. Fill in store details
4. Click "Create"

**Store Types:**
- **HQ**: Headquarters/main store
- **Branch**: Regional branches
- **POP**: Point of Presence locations

### 3.2 Stock Items
**Adding Stock Items:**
1. Navigate to Inventory → Stock Items
2. Click "Add Stock Item"
3. Enter item details
4. Set reorder level
5. Click "Create"

**Item Types:**
- **Asset**: Serialized equipment
- **Solid**: Non-serialized physical items
- **Liquid**: Liquid materials

### 3.3 Stock Transfers
**Transferring Stock:**
1. Navigate to Inventory → Transfers
2. Click "New Transfer"
3. Select source and destination stores
4. Add items
5. Submit for approval
6. Approve and receive

### 3.4 Stock Adjustments
**Adjusting Stock:**
1. Navigate to Inventory → Adjustments
2. Click "New Adjustment"
3. Select store and item
4. Enter new quantity
5. Provide reason
6. Submit for approval

## 4. Release Forms

### 4.1 Creating Release Forms
**Installation Release:**
1. Navigate to Release Forms
2. Click "New Release Form"
3. Select "Installation" category
4. Enter Job Order number
5. Click "Fetch from CRM"
6. Review auto-filled information
7. Add items
8. Add signatories
9. Submit for approval

**Maintenance Release:**
1. Navigate to Release Forms
2. Click "New Release Form"
3. Select "Maintenance" category
4. Enter Ticket number
5. Click "Fetch from CRM"
6. Review auto-filled information
7. Add items
8. Add signatories
9. Submit for approval

**Others Release:**
1. Navigate to Release Forms
2. Click "New Release Form"
3. Select "Others" category
4. Enter reference description
5. Add items
6. Submit for approval

### 4.2 Manual Entry
**For offline forms:**
1. Click "Manual Entry"
2. Upload scanned form
3. Enter form details
4. Add items
5. Submit
6. Reconcile later

### 4.3 Approval Workflow
Draft → Submit → Pending Approval → Approve → Dispatch → Complete

text

### 4.4 Signing Forms
1. Open the release form
2. Find your signatory entry
3. Click "Sign"
4. Confirm signature
5. Form proceeds to next step

## 5. Asset Management

### 5.1 Adding Assets
1. Navigate to Assets
2. Click "Add Asset"
3. Enter asset details
4. Set depreciation method
5. Click "Create"

### 5.2 Assigning Assets
1. Find the asset
2. Click "Assign"
3. Select user
4. Confirm assignment

### 5.3 Depreciation
- Automatic calculation
- Multiple methods supported
- Track current value

## 6. Procurement

### 6.1 Suppliers
1. Navigate to Procurement → Suppliers
2. Click "Add Supplier"
3. Enter supplier details
4. Click "Create"

### 6.2 Purchase Requisitions
1. Navigate to Procurement → Requisitions
2. Click "New Requisition"
3. Enter title and priority
4. Add items
5. Submit for approval

### 6.3 Purchase Orders
1. Navigate to Procurement → Purchase Orders
2. Click "New Purchase Order"
3. Select supplier and store
4. Add items
5. Click "Create"
6. Send to supplier
7. Receive goods

### 6.4 Receiving Goods
1. Open purchase order
2. Click "Receive Goods"
3. Enter received quantities
4. Confirm receipt
5. Stock automatically updated
